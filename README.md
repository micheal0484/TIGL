# TIGL - Mobile Website

TIGL is a simple mobile-optimized website designed to provide a seamless user experience on mobile devices. This project includes a main HTML document and a dedicated CSS file for styling.

## Project Structure

```
TIGL
├── src
│   ├── index.html       # Main HTML document
│   └── styles
│       └── mobile.css   # Mobile-specific styles
└── README.md            # Project documentation
```

## Getting Started

To get started with the TIGL project, follow these steps:

1. Clone the repository to your local machine.
2. Open the `src/index.html` file in a web browser to view the website.
3. Modify the `src/styles/mobile.css` file to customize the styles as needed.

## Features

- Mobile-responsive design
- Simple and clean layout
- Easy to customize
